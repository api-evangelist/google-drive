# Google Drive API

> The Google Drive API v3 is a REST API for creating, reading, updating, and deleting files and folders in Google Drive. It supports file metadata operations, content upload/download (simple, multipart, resumable), folder hierarchies, sharing and permissions, revisions, comments, change tracking, and search across a user's Drive. Authorization is OAuth 2.0 via accounts.google.com. Generated by API Evangelist from the catalog; not published by Google.

## APIs
- [Google Drive API v3](https://developers.google.com/workspace/drive/api/v3/about-sdk): REST API for files, folders, permissions, revisions, and changes. Base URL https://www.googleapis.com/drive/v3.

## Agent access
- [Official MCP server](https://developers.google.com/workspace/drive/api/reference/mcp): Remote MCP at https://drivemcp.googleapis.com/mcp/v1 (OAuth 2.0, developer preview) — search_files, get_file_metadata, read_file_content, download_file_content, create_file, copy_file, get_file_permissions, list_recent_files.
- [Agentic access contracts](https://raw.githubusercontent.com/api-evangelist/google-drive/refs/heads/main/agentic-access/google-drive-agentic-access.yml)

## Auth
- [About authorization](https://developers.google.com/workspace/drive/api/guides/about-auth): OAuth 2.0 Bearer tokens; API keys for public files only.
- [OAuth scopes](https://developers.google.com/workspace/drive/api/guides/api-specific-auth): drive, drive.file, drive.readonly, drive.metadata(.readonly), drive.appdata, drive.activity, and more.
- [OIDC discovery](https://accounts.google.com/.well-known/openid-configuration)
